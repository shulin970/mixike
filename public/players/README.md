# 球员真实照片（可选）

把球员照片（.jpg）放进这个文件夹，应用会自动加载真人头像；没放则用生成的位置色头像。

## 命名规则
文件名 = 球员英文名转 slug（全小写、去重音、空格/标点变 `-`）。

| 球员英文名 | 文件名 |
|---|---|
| Kylian Mbappé | `kylian-mbappe.jpg` |
| Erling Haaland | `erling-haaland.jpg` |
| Lamine Yamal | `lamine-yamal.jpg` |
| Harry Kane | `harry-kane.jpg` |
| Vinícius Júnior | `vinicius-junior.jpg` |
| Son Heung-min | `son-heung-min.jpg` |
| Jude Bellingham | `jude-bellingham.jpg` |
| Cristiano / Messi... | `cristiano-ronaldo.jpg` / `lionel-messi.jpg` |

建议正方形、≥200×200。命名就是「英文名小写、空格用连字符、去掉重音符号」。

## 去哪找图（国内可达）
- 自行截图/下载后重命名丢进来即可（最稳）。
- 或用国内能打开的图床/图片站。

放好后无需改代码，刷新即可看到真人头像。
